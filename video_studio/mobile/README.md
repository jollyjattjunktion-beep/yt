# Preet Sports Studio — Android companion

This folder contains the Android app source. The Android app is a native companion, not a WebView wrapper. It is designed for on-device production and uses Android's media stack for rendering.

## Build

- Android Studio (current stable)
- JDK 17
- Android SDK 35
- Gradle wrapper should be generated by Android Studio on first open if not present.

Open this folder as an Android Studio project and run the app on an Android 10+ device.

## Current implementation stage

The native project shell and secure local settings are being introduced first. The existing Python renderer remains available to the web dashboard. The phone-side rendering pipeline is a separate Android implementation and must pass device tests before it is advertised as production-ready.

Gemini API keys are stored using Android encrypted preferences. Do not commit keys to source control.
